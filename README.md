# Rclone_AutoMountHide 项目说明

## 功能简介
本项目基于 AutoHotkey v2.0 开发，为**Rclone 多网盘批量自动化挂载工具**。采用结构化配置数组统一管理多平台网盘挂载任务，可批量后台启动 Rclone 挂载进程，自动调起 RBTray 程序，将所有挂载命令行窗口统一收拢至系统托盘驻留。全程静默执行，无冗余前台弹窗与常驻窗口，实现挂载流程**后台无感自动化运行**。

## 核心特性
1. 模块化配置管理：通过内置数组集中维护挂载规则，支持快速增删挂载节点、调整盘符分配、修改卷标名称及追加自定义运行参数，配置逻辑清晰易维护。
2. 依赖自动自检启动：程序自动检测 RBTray 运行状态，未启动时将自行拉起，无需人工前置手动开启依赖程序。
3. 错峰延时启动机制：各挂载任务按时序错开初始化，规避多命令行窗口同时创建引发的资源抢占、挂载异常及启动冲突问题。
4. 全自动窗口托管收敛：逐个定位挂载命令行窗口，自动激活并调用 RBTray 快捷键规则，统一最小化收纳至系统托盘后台驻留。
5. 程序自身静默无驻留：脚本运行期间隐藏自身托盘图标，全部挂载任务处理完成后自动退出，不占用后台进程与系统托盘资源。
6. 原生兼容 Rclone 参数体系：内置成熟稳定的基础挂载参数，支持自定义缓存策略、缓冲区大小、网络运行模式等高级配置扩展。

## 运行环境与依赖
- 适配系统：Windows 全系列桌面系统
- 必备依赖组件：
  1. [AutoHotkey v2.0](https://www.autohotkey.com/)
  2. [Rclone](https://rclone.org/) 主程序，已提前完成各网盘 Remote 节点配置
  3. RBTray 窗口托盘托管工具

## 配置规范说明
使用文本编辑器打开脚本，直接编辑顶层 `mounts` 配置数组即可完成自定义配置：
- remote：填写 Rclone 已配置的网盘 Remote 别名，需与配置项严格一致
- drive：指定挂载映射的本地盘符，仅限单个大写英文字母
- label：设置挂载磁盘在资源管理器中展示的卷标名称
- extra：补充追加 Rclone 额外启动参数，无需扩展时留空即可沿用默认参数

## 标准运行流程
1. 部署 RBTray 程序，可放置于脚本同级目录，或将其所在路径添加至系统 Path 环境变量，保证程序可全局调用。
2. 依据个人网盘配置、空闲盘符规划，修改脚本内挂载配置数组。
3. 双击执行 `Rclone_AutoMountHide.ahk`，等待数秒初始化完成，所有网盘将自动挂载并收纳至系统托盘。
4. 支持创建程序快捷方式，放入系统开机启动目录，实现开机全自动静默挂载。

## 注意事项
1. 分配挂载盘符前需确认系统已有磁盘、虚拟磁盘占用情况，严禁盘符冲突，防止挂载任务初始化失败。
2. 脚本内延时休眠参数可依据设备硬件性能酌情调整，低配设备建议适当增大延时数值，保障挂载稳定性。
3. 需断开网盘挂载时，可在系统托盘找到对应 CMD 窗口图标，展开并关闭命令行进程，即可安全卸载挂载节点。
4. 若自行修改 RBTray 全局快捷键，需同步对应修改脚本内托盘收拢快捷键指令，避免窗口托管失效。
